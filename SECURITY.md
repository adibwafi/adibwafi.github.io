# Security Policy

This repository is the source of the personal portfolio at
[adibwafi.com](https://www.adibwafi.com). It is a static Next.js site: no user
accounts, no database, and no secrets in the repository.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

- Use GitHub's private reporting: **Security → Report a vulnerability** on this
  repository, or
- email [hello@adibwafi.com](mailto:hello@adibwafi.com) with the details.

I will acknowledge a report within a few days and keep you updated until it is
resolved.

## Scope

In scope: the deployed site and the code in this repository.
Out of scope: third-party services (Vercel, Google Analytics, Sentry, YouTube)
and social engineering.
